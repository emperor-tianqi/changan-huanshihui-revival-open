# 术语表（看不懂就查这里）

## 服务端 / 客户端

- **客户端**：手机上那个游戏 App（原版 0.1.20.1）。
- **服务端**：电脑上这个 Python 程序，负责回游戏的数据。
  原版服务端在游戏公司机房；现在用你电脑上的这个代替。

## 端口

电脑上跑很多程序，端口就是“门牌号”。

- **46002**：游戏登录、存档、战斗走的门。
- **38083**：游戏启动时下载服务器列表走的门。

两个端口都要通，手机才能连上。

## ADB

Android Debug Bridge，谷歌提供的电脑↔手机调试工具。
本项目用它做两件事：

1. 检查手机有没有连上；
2. 把手机的端口“反向映射”到电脑（见下）。

## 反向映射（adb reverse）

手机以为自己在连“自己”（127.0.0.1），实际上被 ADB 转到了电脑上的服务端。
所以：

- 必须插着 USB；
- 每次重新插拔后，要重新运行 connect_phone.ps1。

## Lua 垫片（client_shim）

游戏自带一个“热更新脚本”目录（update/luaScript）。
本项目的垫片放到这个目录后，游戏启动时会优先读它，
从而跳过第三方 SDK 登录、走本地服务端。

垫片是**我们自己写的**，不是原版代码，也不修改 APK。

## 存档

角色、卡牌、背包等数据，存在电脑上：

    %LOCALAPPDATA%/chang_an_revival_profiles/main/revival_roles.sqlite3

删掉这个文件 = 删档。备份就是复制整个 main 文件夹。

## 协议 / 包

客户端和服务端之间传输的数据格式。
每个操作（登录、抽卡、进副本）都是一次“包”的往返。

## 预览版（preview）

意思是“能跑，但没做完”。请以 FEATURE_STATUS.md 为准，
不要期待整款游戏 100% 复原。

## 开发模式 / 测试档案

给开发者调试用的开关（送资源、调等级）。
普通玩家**不要**用，会污染正常存档。
