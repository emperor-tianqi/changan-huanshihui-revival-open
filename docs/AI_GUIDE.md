# 让 AI 帮你安装、调试与继续开发

> 你不需要会写代码，也可以把本仓库交给 DeepSeek、Claude Code、ChatGPT 等 AI 工具。
> 下面四段提示词可以直接复制。**复制前先确认 AI 能访问到本仓库文件和你的电脑。**

## 使用前须知

- AI 可以改代码，但**不保证改完一定能运行**；改之前先备份存档。
- 调试（测试等级/资源）与正常游玩必须分开，不要让 AI 直接改你的正式存档。
- **不要**把账号密码、Token、完整存档、身份证件交给 AI 或贴到公开 Issue。
- 反馈问题时提供脱敏信息：
  - 服务端窗口最后 30 行日志（去掉路径里的用户名）
  - 手机型号、安卓版本、客户端版本
  - 你点了哪个按钮、期望什么、实际什么

## 提示词 A：首次安装

```text
这是我下载的《长安幻世绘》复原项目。请先阅读 README.md 和 docs/PLAYER_GUIDE.md，
检查我的 Windows 环境（Python 版本、ADB、端口），
逐步帮助我启动服务端并连接安卓手机。
优先执行已有脚本（scripts/ 目录），不要重写项目，也不要删除存档。
每一步告诉我应该看到什么输出；失败时先让我把报错贴给你。
```

## 提示词 B：遇到 BUG

```text
游戏现在出现了这个问题：[在这里描述，例如“点开魔涧副本详情后点进入没有反应”]。
请先检查当前代码、服务端日志和 FEATURE_STATUS.md 里已知问题，
找到第一个真正失败的步骤，再做最小修复。
保留存档，完成相关测试，并告诉我怎样重新进入游戏验证。
不要修改 client_shim 以外的客户端内容，也不要改动我的正式存档。
```

## 提示词 C：调整测试等级与资源

```text
我希望使用独立测试档案，把角色调整到指定等级，并提供足够的测试资源，
用于体验尚未正常解锁的玩法。
请根据项目现有 dev-play 机制操作（参考 docs/DEV_NOTES.md 和 revival_stub/app.py 的参数），
不要直接破坏正式存档，不要伪造已经恢复的原版游戏规则。
先把原存档备份，再创建独立测试档案；完成后告诉我怎么切回正常游玩。
```

## 提示词 D：继续修复新玩法

```text
我想恢复这个系统：[系统名称，例如“昆仑装备副本的战斗”]。
请先阅读 FEATURE_STATUS.md、docs/DEV_NOTES.md 里的协议研究和已知问题，
复用已有实现（revival_stub/ 下对应模块）。
按完整可玩流程开发、测试、验证，不要只补一个网络协议就宣称完成。
需要真机验证的步骤请明确标出来，不要编造成功结果。
```

## AI 常见误区（请提醒你的 AI）

1. **“协议回包 = 功能完成”**：不对。客户端还要渲染、交互、结算。
2. **直接改 `%LOCALAPPDATA%` 下的存档**：危险。先备份。
3. **把调试开关写进正常启动脚本**：会污染正式游玩。
4. **要求你上传 APK/存档**：不要给；让 AI 在本地读日志即可。
5. **承诺“100% 复原”**：本项目是预览版，做不到。
